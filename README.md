# Design Skills

A collection of detailed design skills for creating and refining high-quality, modern websites with a strong visual identity.

## Current Skills

The current skills are primarily designed for **technology-focused websites**, as the included Apple and Google design references are both strongly associated with the tech industry.

They are especially useful for:

- Technology websites
- SaaS products
- AI platforms
- Software products
- Startups
- Modern web applications
- Product landing pages

## Best Used for Website Editing

These skills are **primarily designed for improving and refining existing websites**, rather than creating an entire website completely from scratch.

You can absolutely use the skills to build a website from zero — and doing so can result in a significantly better design. However, the skills are most valuable when **editing, redesigning, and polishing an existing website**.

For example, they can help you:

- Improve an existing UI
- Refine layouts and spacing
- Upgrade animations and interactions
- Improve colors, typography, and visual hierarchy
- Make buttons and components feel more polished
- Add intentional micro-interactions
- Improve the overall visual experience
- Make an existing website feel more professional and cohesive
- Refine the small details that make a website feel premium

**In short:** these skills work best as a design layer that you apply to an existing website to take its design to the next level.

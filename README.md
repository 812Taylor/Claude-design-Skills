# Design Skills

A collection of detailed design skills for creating high-quality, modern websites with a strong visual identity.

## Current Skills

The current skills are primarily designed for **technology-focused websites**, as the included Apple and Google design references are both strongly associated with the tech industry.

They are especially useful for:
- Technology websites
- SaaS products
- AI platforms
- Software products
- Startups
- Modern web applications
- Product landing pages

## More Themes Coming Soon

This is only the beginning.

More design skill files for **different industries, aesthetics, and visual themes** will be added soon. The goal is to build a growing collection of specialized design systems that can be used depending on the type and personality of your website.

Stay tuned for more.
